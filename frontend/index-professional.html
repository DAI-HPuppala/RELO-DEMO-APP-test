RELO Classifier User Guide

Operation Modes

Automatic Mode: Ideal for high-volume processing. System continuously analyzes garments with minimal operator intervention, maximizing throughput for busy return periods.
Manual Mode: Perfect for quality control and training. Operators can step through each analysis stage, review results, and ensure accuracy for high-value items or disputed returns.

Control Panel

Start: Begin classification process. Camera activates and analysis pipeline starts processing garments placed in view.
Pause/Resume: Temporarily halt processing while maintaining current session state. Useful for handling customer inquiries or equipment adjustments.
Stop: End current session and finalize all results. Use when switching operators or completing a batch of returns.

Analysis Pipeline

Initial Analysis: Identifies garment type, color, pattern, and basic features. Forms foundation for return eligibility assessment.
Detail Extraction: Reads brand labels and size tags for verification against customer claims and inventory records.
Damage Detection: Inspects for wear, stains, or defects that could affect resale value or return policy compliance.

Results Management

Classification Table: Real-time results display with newest items at top. Each row represents one processed garment with complete attribute analysis.
Export Functions: Generate CSV reports for inventory systems or JSON data for integration with existing retail management platforms.

Best Practices

Use Manual Mode when training new staff, handling premium items, or when return policies require human verification. Automatic Mode maximizes efficiency during peak return periods while maintaining consistent analysis standards.
